人们以为星星是自己在转。其实，天空是一只八音盒：北极星是轴，每一颗星都是一枚音钉，转过山顶那把看不见的音梳时，就拨响一个音。

直到有一天夜里，发条松了，天空停了下来。于是一个提着灯笼的孩子爬上了天空，在北斗第七星"摇光"上，找到了天空的摇柄。

片名里的"上弦"有三层意思：给发条上弦、音乐的弦，以及片尾升起的上弦月。

## 关于这部片子

- 画面、音乐、音效全部由代码生成，没有使用任何图片、音频或模型素材。
- 星图就是乐谱：每颗音钉星的角度对应它在乐谱里的拍位，离北极星的距离对应音高。画面里每一次闪光，都是同一个音符。
- 孩子爬音梳时踩响一段上行音阶，沿音梳滑落时奏出下行滑音；上弦时群星倒转，倒放出幽灵般的回声。
